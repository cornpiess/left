# 限时优惠：只维护 promotions.json

[点击编辑活动配置](https://github.com/cornpiess/left/edit/main/config/promotions.json)

每个国家只填三个值：币种、常规价、活动价。App 自动翻译文案、格式化金额并计算“立省”，不用填折扣百分比或各语言文案。

目前已经配置：中国大陆（CHN），人民币（CNY），98 → 78。**没有配置的地区不显示优惠。**

## 每次活动怎么操作

1. 在 ASC 设置真正的临时售价和调价日期。
2. 在 `promotions.json` 填入相同的活动价和真实常规价，提交到 `main`。
3. App 下次打开付费页成功获取配置后，只有“商店地区、币种、Apple 当前售价”全部匹配才显示优惠。
4. ASC 恢复常规价后，App 下次刷新价格就会隐藏优惠。提前取消宣传，删除该国家那一段即可。全部关闭用 `"lifetime": {}`。

**不需要发 App 新版，不需要改内购商品 ID，也不需要新建活动商品。**首次接入这套功能仍需要发一版。

## 不同国家：同一个文件，各写一行规则

`lifetime` 下的键使用 Apple 的三位商店地区代码，不是手机语言或所在地。

| 国家/地区 | 商店代码 | 币种 |
|---|---|---|
| 中国大陆 | CHN | CNY |
| 美国 | USA | USD |
| 日本 | JPN | JPY |
| 韩国 | KOR | KRW |
| 中国台湾 | TWN | TWD |
| 中国香港 | HKG | HKD |
| 新加坡 | SGP | SGD |
| 英国 | GBR | GBP |
| 加拿大 | CAN | CAD |
| 澳大利亚 | AUS | AUD |

例如，以下是**格式示例，不是已启用的美国活动**：

```json
{
  "version": 1,
  "lifetime": {
    "CHN": { "currency": "CNY", "regularPrice": 98, "salePrice": 78 },
    "USA": { "currency": "USD", "regularPrice": 14.99, "salePrice": 9.99 }
  }
}
```

金额填数字，不能写 `"¥78"` 或 `"78"`。国家之间用逗号分隔，最后一项后面不加逗号。

## 日期默认不用填

这次没有提供 ASC 的具体起止日期，所以没有编造日期，也不显示倒计时。默认以 Apple 实际是否正在卖活动价为准。

需要额外限制展示时间时，可在某个国家的规则中添加 `startsAt`、`endsAt`；二者均可省略。时间必须写明时区，例如 `"endsAt": "2026-11-12T00:00:00+08:00"` 表示北京时间 11 月 12 日零点起停止展示（只是格式示例）。结束时刻不包含在活动内。它们只会进一步限制展示，不能覆盖 Apple 售价校验。

## 读取与失败处理

- 固定地址：`https://raw.githubusercontent.com/cornpiess/left/main/config/promotions.json`。直接使用现有公开仓库，无需新建仓库、开通 Pages 或配置密钥。文件中只放公开活动信息。
- 只随用户主动加载付费页价格读取；App 启动、相册浏览、自动配额提示、恢复购买不会额外请求配置。
- 配置请求最多等待 4 秒，与价格加载并行；不影响购买，也不弹出额外错误。
- 不持久化旧配置。失败、格式错误、未知地区、价格不符时只显示 Apple 当前价。一次成功读取的活动信息最多展示 5 分钟；付费页长期打开也会自动隐藏过期标签。
- GitHub 缓存或大陆网络可能延迟读取，因此不承诺即时更新；连接失败只影响促销展示。
- 目前规则针对终身买断。包年订阅涉及续费价格和优惠资格，不套用这套买断优惠规则。
- `npm run promotions:check` 验证格式；PR 和 main 的测试也会自动校验。校验无法替你核实 ASC 是否设置正确，前端会以实际商品价格再次校验。
