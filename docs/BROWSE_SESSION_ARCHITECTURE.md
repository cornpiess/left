# 连拍分组 出现节奏与浏览恢复

适用版本 v287。所有计算在本地完成，不增加交互入口，不引入图像识别或大模型。方案源自用户确认的连拍与恢复技术方案，基线为 master 的 8adf6f508c80f468bc531096ee590ea9b7da360e。

2026-10-28 首屏加载 P0 修复及防回归门禁见 [P0_PHOTO_STARTUP.md](P0_PHOTO_STARTUP.md)。

## 一个数据流

系统元数据 → 分组与分页闭组 → browseSession 有界候选池 → 已承诺展示窗口 → 实际曝光 → SQLite 快照。

分组只判定拍摄关系，浏览会话负责安排出现时机和当前位置，界面是投影。SQLite 的已读、待删、额度仍为整理事实；快照不复制这些事实。PhotoKit 仍为存在性、权限和收藏事实源。

## 分组

系统连拍不受普通时间/方向/宽高比限制，按 burstIdentifier 读取可访问成员，显式 includeAllBurstAssets。元数据每次最多160项，当前组接近尾部时补读；旧已读帧离开元数据邻域，未读帧进入持久回流。组关系不因分段读取而改变。

普通组相邻不超过2秒、总跨度不超过15秒、至少2张、横竖一致、宽高比差异不超过5%。拍摄时间和尺寸必须有效。Live Photo 可以参与；视频、截图、全景、空间媒体为边界，不通过先过滤再跨过它们合组。元数据异常密集时按最多160成员形成有界展示段，所有成员继续参与。

按拍摄时间和 ID 确定顺序，在局部完整元数据上分组后再过滤已读/待删。candidatePager 保留页尾未闭合组。输出保留单元，不为凑50个媒体拆组。Home 不再调用 assignBursts；待删过滤后组 key 仍稳定。

## 出现节奏

候选充足时，首次先2张单卡，此后两组间3–5张新单卡，每次选定的间隔保存到快照。时间间隔参数和节奏参数集中在 algorithmConfig.mjs。

首屏、分页、云端就绪、离组未读回流和原生后续成员都进入同一候选池。默认/空间优先只影响队列内部优先次序。

只有主流新单元成功展示才推进节奏；预取、组内切帧、回看、同日浏览、恢复同一节点不重复计数。使用单调向前边界，窗口裁剪不让计数归零。预排用于极短邻域，实际曝光与预排分开；快速跳过未显示的卡片，在新组停稳前校验最小间隔，必要时只调整其未曝光展示形式。

没有组时继续单卡，不积累补发欠账。后台补充受最多2次分页轮次与候选容量限制，不等待全库扫描。有组晚到时安排到最早未承诺位置。只有组且没有独立单卡时，部分尚未展示组改为逐张呈现；不拆已经打开的组，不遗漏或重复成员。

## 同一快照

复用 reviewStore 的 meta 表存 browse-session，最大512KiB。包含版本、epoch/revision、候选和溢出、未读回流、原生续页句柄、已承诺窗口、当前 assetId、组内位置、同日窗口与返回锚点，以及节奏进度。

图像、播放器、沙盒 URI、GPS 和全库目录不进入快照。保存白名单元数据，原生加载锁不持久化。主流保存当前附近窗口，同日最多320项；候选主池480媒体，生产者溢出和原生元数据窗口另外有界。

列表停稳或组内切帧即保存，后台刷新补充。写入串行且带 revision，resetBrowse 增加 epoch，禁止旧会话异步结果复活旧进度。已读清空与额度仍解耦。

选择待删与后继锚点在同一 SQLite 事务写入；失败、取消或超额不推进。撤回定位当前资产，待删相册恢复保留底下浏览节点。恢复位置是最后已持久化的稳定节点，不能承诺保存强杀时尚未完成的写盘。

## 冷启动

读取快照，优先校验当前媒体；同日模式优先校验同日当前帧。恢复组身份、组内 assetId、已承诺顺序和节奏，首先显示原节点。远处媒体在后台分批校验。

恢复上下文允许已读照片，不放回新推荐。已待删、系统删除或权限不可访问的锚点按原顺序寻找后继，再找前驱。网络异常不等于资产消失。PhotoKit 只用于权限/存在性校验，不为恢复导出原图。

不足的后续候选再后台建立；不把上一进程的临时 PhotoKit 游标当作永久契约。旧首40项缓存只作一次升级兼容，不再写入。新照片不插入当前节点之前。损坏快照只重置浏览会话，不清空已读、待删或额度。

## 验证

纯函数覆盖阈值、边界、跨页、节奏、预取与实际曝光、乱序写入和快照预算。SQLite 验证清理与锚点原子性、超额、失败回滚、重启、epoch 和损坏快照。

集成测试执行生产 media 管线，验证候选到实际分组/排期、已读锚点恢复、待删后下一帧、系统代表帧扩展全组、350帧原生续页与离组/重启不丢失，以及同日恢复。

发布前需要新二进制的 Xcode 编译和真机回归：普通/Live/视频、有限权限、iCloud弱网、切后台与强杀、超大图库和大连拍。JS/Hermes 导出不代表原生编译或性能测量。
