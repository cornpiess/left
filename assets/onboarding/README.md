## Device acceptance

- First launch: start CTA stays visible on small screens and with large text. Request access immediately, including during animation. Accept limited access; deny, open settings and return; retry errors.
- Autoplay: browse once, then select once, stop. Touch, background or opening help cancels autoplay; no delayed ghost selection. Reduced Motion uses immediate state changes.
- Sandbox: up/down, left/right, undo; repeated/short/diagonal swipes; no changes to real pending photos, history, favorites or quota.
- Replay: menu opens the same scene; close/back works; no new photo permission prompt.
- Real feed: no automatic teaching pills or teaching-driven photo displacement; actual selection/error/undo feedback remains.
- Check Chinese (simplified/traditional), English, Spanish, Japanese and Korean. Native iOS visual and gesture acceptance remains a device check; Metro export is not a device test.
